# .gen-ai_instructions.md

**Purpose:** Define safe rules for automated AI code generation in this repository.

---

## 1. Intent

Maintain stable, modular, and minimal AI-assisted edits for the Nekobo robotics platform.  
Prevent breaking changes or cross-layer contamination between `application`, `middleware`, and `firmware`.

---

## 2. Project Context

- Project root: contains `software/`, `hardware/`, `docs/`, etc.
- Runtime: Raspberry Pi 4 (Python 3.10+), Arduino (AVR/ESP32)
- Default scope: only modify files under `software/`

---

## 3. Folder Responsibilities

| Folder                  | Description                                  |
| ----------------------- | -------------------------------------------- |
| `software/application/` | Main logic and student-facing code           |
| `software/middleware/`  | Communication and control bridge (RP4 ↔ MCU) |
| `software/firmware/`    | Arduino code (C++/embedded)                  |
| `software/tools/`       | Utility scripts and AI rules                 |

---

## 4. Safety Rules

- Only modify files under `software/` unless explicitly listed.
- Never reformat unrelated code or change unrelated imports.
- Never delete or rename existing files.
- Ask **one short clarifying question** if missing key info.
- Keep all patches minimal and atomic.

---

## 5. Workflow

1. Create TODO list with `todo` tool.
2. Apply edits via `apply_patch`.
3. Run `get_errors` and report output.
4. (If possible) Run minimal smoke tests or `pytest`.
5. Summarize changes, list edited files, and describe test results.

---

## 6. Coding Standards

- Match file style and indentation.
